# Hamsa — download

Private family messenger. You need an account from your family's admin to use it.

## Current version: TEST BUILD 1.0.14

**Download on the Android phone:** https://github.com/broky1989/hamsa-download/raw/main/hamsa-test.apk

This is a **test build** (signed with a test key, shown as "Test build" in the app), not the final family version.
Newer test builds install over it without uninstalling. When the final family version is published, the test build
is uninstalled once; accounts and messages are kept on the server.

1. Open the link above on the phone and download `hamsa-test.apk`, then open it.
2. If Android asks, allow your browser to *install unknown apps* (only for this install).
3. Sign in with the username and temporary password from your family admin; you will choose your own password.
   The app finds the family server by itself (no address to type).

SHA-256 of the file: see `SHA256SUMS`. This repository contains only the app file. There is no public sign-up.
