# Hamsa — download

Private family messenger. You need an account from your family's admin to use it.

**Download on the Android phone:** https://github.com/broky1989/hamsa-download/releases/latest/download/hamsa.apk

1. Open the link above on the phone, download `hamsa.apk`, open it.
2. If Android asks, allow your browser to *install unknown apps* (only for this install).
3. Sign in with the username and temporary password from your family admin; you will choose your own password.

New versions install over the old one (no need to uninstall). Each release lists the file's SHA-256 checksum.

This repository contains only the app file. There is no public sign-up.
